# Whitney Waceke Wanjiku — Portfolio

Personal portfolio website for **Whitney Waceke Wanjiku**, a Communication & Public Relations
professional specialising in strategic communication, social media, content development,
media relations, event communication and photography.

## Tech Stack

- **Vite** — build tooling and dev server
- **Bootstrap 5** — layout and components (SCSS-customised)
- **GSAP + ScrollTrigger** — scroll animations
- **Sass** — styling

## Getting Started

1. Clone the repository
```bash
git clone https://github.com/steve-kings/Whitney-Waceke.git
```

2. Install dependencies
```bash
npm install
```

3. Run the development server
```bash
npm run dev
```

The site is served at `http://localhost:3000`.

## Build

```bash
npm run build
```

Production files are output to `dist/`.
